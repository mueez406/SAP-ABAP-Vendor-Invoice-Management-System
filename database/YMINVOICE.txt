YMINVOICE
=========

Purpose
-------

YMINVOICE stores the invoice information used in the Vendor Invoice
Management System.

Fields Used in the Project
--------------------------

1. INVOICE_ID
   Unique identifier of the invoice.

2. VENDOR_ID
   Identifies the vendor associated with the invoice.

3. INVOICE_DATE
   Date on which the invoice is created.

4. DUE_DATE
   Payment due date of the invoice.

5. AMOUNT
   Total invoice amount.

6. PAID_AMOUNT
   Amount already paid against the invoice.

7. BALANCE
   Remaining amount to be paid.

8. STATUS
   Indicates the current invoice status.
   Possible values used by the program:
   - PENDING
   - PAID

9. CREATED_BY
   SAP user name of the user who created the invoice.


Invoice Creation Logic
----------------------

When an invoice is created:

- INVOICE_ID is generated by the program.
- VENDOR_ID is taken from the selected vendor.
- INVOICE_DATE is set using SY-DATUM.
- DUE_DATE is entered by the user.
- AMOUNT is entered by the user.
- PAID_AMOUNT is initially set to 0.
- BALANCE is initially equal to AMOUNT.
- STATUS is set to PENDING.
- CREATED_BY is set using SY-UNAME.


Payment Update Logic
--------------------

When a payment is entered:

New Paid Amount = Existing Paid Amount + New Payment

Balance = Invoice Amount - New Paid Amount

If Balance = 0:
    STATUS = PAID

Otherwise:
    STATUS = PENDING

The program prevents payment when the payment amount is greater
than the remaining invoice balance.


Usage in the Project
--------------------

YMINVOICE is used for:

1. Creating invoices
2. Updating invoice payments
3. Displaying pending invoices
4. Displaying paid invoices
5. Displaying vendor-wise invoice details
6. Generating payment receipts


Related Table
-------------

YMVENDOR

YMINVOICE is linked with YMVENDOR using VENDOR_ID.
